# Feature Specification: ナビゲーション統一（Bottom Nav）

**Feature Branch**: `007-unified-bottom-nav`  
**Created**: 2026-06-07  
**Status**: Draft  
**Input**: User description: "これまで検討した方向での変更を行いたいと思います。（審判・管理ともにbottom navを採用し、ホーム画面にも戻れるように統一する。コミュニティ参加はプロフィールページに統合する）"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 審判ユーザーがbottom navでホームと審判機能を切り替えられる (Priority: P1)

審判ユーザーがプロフィール・空き日程・担当履歴のいずれの画面からもbottom navのホームアイコンをタップしてホーム画面に戻ることができる。

**Why this priority**: FR-009（ホームへの戻り導線）の実現。現行では審判レイアウトのbottom navにホームへのリンクがなく、ホームに戻るにはヘッダーロゴを使うしかない。一貫した操作感を提供することが基本要件。

**Independent Test**: 審判ロールのアカウントで `/profile`・`/availability`・`/history` それぞれにアクセスし、bottom navの「ホーム」をタップして `/` に遷移することを確認。bottom navに「コミュニティ」アイテムがないことも確認。

**Acceptance Scenarios**:

1. **Given** 審判ユーザーが `/profile`（または `/availability`、`/history`）を表示しているとき、**When** bottom navの「ホーム」をタップすると、**Then** `/` のホーム画面に遷移する
2. **Given** 審判ユーザーがhome画面にいるとき、**When** 審判機能のエントリーポイントをタップすると、**Then** 対応する審判機能画面（プロフィール等）に遷移する
3. **Given** 審判ユーザーが各審判機能画面にいるとき、**When** bottom navを確認すると、**Then** 現在地に対応するアイコンがアクティブ状態で表示される

---

### User Story 2 - 管理ユーザーがbottom navでホームと管理機能を切り替えられる (Priority: P1)

管理ユーザー（organizer/manager）が管理画面（試合管理・メンバー管理）からbottom navでホームに戻ったり、管理機能間を切り替えられる。現在のヘッダータブはbottom navに置き換えられる。

**Why this priority**: 管理ユーザーの画面が現在ヘッダータブ方式でありモバイルUXとして一貫性を欠く。特に兼任ユーザーが管理画面からホームに戻る自然な導線がない。

**Independent Test**: organizer/managerロールのアカウントで `/admin/matches` にアクセスし、bottom navの「ホーム・試合管理・メンバー管理」が表示されることを確認。「ホーム」タップで `/` に戻ることを確認。ヘッダーにタブが存在しないことを確認。

**Acceptance Scenarios**:

1. **Given** 管理ユーザーが `/admin/matches`（または `/admin/members`）を表示しているとき、**When** bottom navの「ホーム」をタップすると、**Then** `/` のホーム画面に遷移する
2. **Given** 管理ユーザーが `/admin/matches` にいるとき、**When** bottom navの「メンバー管理」をタップすると、**Then** `/admin/members` に遷移する
3. **Given** 管理ユーザーが管理画面にいるとき、**When** 現在地のbottom navアイコンを確認すると、**Then** 現在地に対応するアイコンがアクティブ状態で表示される
4. **Given** 管理画面のヘッダーを確認すると、**Then** ヘッダータブ（試合管理・メンバー管理の切り替えタブ）は表示されない

---

### User Story 3 - 審判ユーザーがプロフィール画面からコミュニティに参加できる (Priority: P2)

コミュニティへの参加は審判プロフィールの一部として位置づけ、プロフィールページ下部に「所属コミュニティ」セクションを設け、そこから `/join` に遷移できる。bottom navの「コミュニティ」は廃止する。

**Why this priority**: コミュニティへの参加は初期設定的な操作であり、毎日使う機能ではないため、bottom navの専用スロットを占有するよりプロフィールと概念的に近い場所に置く方が適切。

**Independent Test**: 審判ロールのアカウントで `/profile` にアクセスし、ページ下部に「所属コミュニティ」セクションが表示されることを確認。「コミュニティを追加」タップで `/join` に遷移することを確認。bottom navに「コミュニティ」アイテムがないことを確認。

**Acceptance Scenarios**:

1. **Given** 審判ユーザーがプロフィールページを表示しているとき、**When** ページ下部をスクロールすると、**Then** 「所属コミュニティ」セクションが表示される
2. **Given** 所属コミュニティが存在するとき、**When** 「所属コミュニティ」セクションを確認すると、**Then** 各コミュニティ名と承認ステータス（承認済み・申請中）が表示される
3. **Given** 「コミュニティを追加」ボタンをタップしたとき、**When** 遷移が完了すると、**Then** `/join`（コミュニティ一覧）が表示される
4. **Given** 所属コミュニティが0件のとき、**When** 「所属コミュニティ」セクションを確認すると、**Then** 空状態メッセージと「コミュニティを追加」ボタンが表示される

---

### Edge Cases

- 兼任ユーザー（organizer + referee）が審判bottom navのホームをタップした場合も `/` のホーム画面に遷移する（管理画面のbottom navと同一動作）
- `/join` ページ自体は `(referee)` レイアウト配下に残るため、そこでも審判bottom nav（ホーム・プロフィール・空き日程・担当履歴）が表示される
- `rejected` ステータスのコミュニティメンバーシップは「所属コミュニティ」セクションに表示しない
- 管理画面の下部コンテンツがfixed bottom navに隠れない（スクロール余白が確保されている）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 審判レイアウトのbottom navは「ホーム（/）・プロフィール（/profile）・空き日程（/availability）・担当履歴（/history）」の4項目でなければならない
- **FR-002**: 審判レイアウトのbottom navから「コミュニティ（/join）」アイテムを削除しなければならない
- **FR-003**: 管理レイアウトはヘッダータブを廃止し、「ホーム（/）・試合管理（/admin/matches）・メンバー管理（/admin/members）」の3項目のfixed bottom navを持たなければならない
- **FR-004**: 管理レイアウトのコンテンツエリアはfixed bottom navに隠れないよう十分な下部余白を持たなければならない
- **FR-005**: プロフィールページ（/profile）はフォームの下部に「所属コミュニティ」セクションを表示しなければならない
- **FR-006**: 「所属コミュニティ」セクションは、ユーザーのコミュニティメンバーシップ（pending/approvedのもの）をコミュニティ名とステータスとともに一覧表示しなければならない
- **FR-007**: 「所属コミュニティ」セクションは「コミュニティを追加」ボタンを持ち、タップで `/join` に遷移しなければならない
- **FR-008**: bottom navは現在表示中のページに対応するアイテムをアクティブ（視覚的に選択中）状態で表示しなければならない

### Key Entities

- **BottomNavItem（審判）**: リンク先・ラベル・アイコンの4項目（ホーム・プロフィール・空き日程・担当履歴）
- **BottomNavItem（管理）**: リンク先・ラベル・アイコンの3項目（ホーム・試合管理・メンバー管理）
- **CommunityMembership**: コミュニティID・コミュニティ名・ステータス（pending/approved）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 審判ユーザーがどの審判機能画面からもbottom navの1タップでホーム画面に到達できる
- **SC-002**: 管理ユーザーがどの管理機能画面からもbottom navの1タップでホーム画面に到達できる
- **SC-003**: 管理画面の全サブページでbottom navが表示され、ヘッダータブが完全に削除されている
- **SC-004**: 審判ユーザーがプロフィールページから2タップ以内でコミュニティ参加画面（/join）に到達できる
- **SC-005**: 兼任ユーザーが審判画面と管理画面の間をホーム経由で自然に切り替えられる

## Assumptions

- ホーム画面（`/`）自体にはbottom navを追加しない（ハブページとして機能する）
- `/join` ページは `(referee)` レイアウト配下に残し、審判bottom navが引き続き表示される
- 管理レイアウトの横幅設定はそのまま維持し、bottom navのみ追加する
- 「所属コミュニティ」セクションのデータはプロフィールページのロード時に取得する
- bottom navのアクティブ状態はパス完全一致または前方一致（/admin/* 等）で判定する
- 管理画面ヘッダーのブランド表示（RefLink 管理）はそのまま残す
